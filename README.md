# Composição e substitutivos de suplementos

Formulário web que gera o texto de rótulo (composição básica qualitativa, eventuais substitutivos, modo de usar e restrições) de suplementos minerais para bovinos, com o log das respostas no final.

É a versão web do notebook do Colab "Composição e Substitutivos - Suplementos - Rural (v2)". O texto gerado é idêntico ao do notebook.

Página publicada: https://maigeldreyer.github.io/IN-12-2004/

## Arquivos

- `index.html`: o formulário.
- `relatorio.js`: a lógica do relatório. Para mudar ingredientes, substitutivos ou recomendações, edite este arquivo. Se mudar aqui, mude também no Colab (e vice-versa).

A página não usa fontes, bibliotecas nem serviços externos, e todo o processamento acontece no navegador. Nada do que é digitado é enviado para nenhum servidor.
